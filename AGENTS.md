# Tic Tac Toe Extended Project

## Commands
- Server: `cd server && node server.js` (starts on port 3001)
- Client: `cd client && npm run dev` (starts on port 5173)

## Tech Stack
- Server: Node.js, Express, Sequelize, SQLite, bcryptjs
- Client: React, Vite, Axios, React Router

## Features
- 7x7 game board
- Random obstacles (cells blocked for placing marks)
- Score points for each 3+ in a row combination
- Player registration/login
- Create/join games
